# 演出表

パチンコ演出の「文法」（予告 → リーチ → 発展 → 結果、色で信頼度を表す）を借りて、研究時間の記録を盛り上げる。既存機種のキャラクター・音・ロゴは使わず、絵も音もすべて自作する。

## 守ること

- 記録はボタンを押した瞬間に保存する。演出はその上に重ねるだけ。
- 演出中は画面のどこをタップしても（Esc・Enter・Space でも）すぐ消える。「押せ！」の間だけはタップがボタンを押す操作になり、Esc で消える。
- 演出の ON/OFF と音の ON/OFF を選べる。音は最初オフ。
- OS の「視差効果を減らす」がオンなら、揺れ・光・粒子なしの文字だけの演出にする。
- 強い点滅を使う。点滅がつらいときは演出をオフにする（設定の画面にも書いてある）。

## 描き方

- 始める演出と止める演出の全段階を WebGL（PixiJS、[effects/gl.js](../effects/gl.js)）で描く。発光（ブルーム）、衝撃波のゆがみ、ズームブラー、カメラの寄り引き、当たる瞬間の一瞬の静止（ヒットストップ）を使う。背景は不透明で、タイムカードの画面は見せない。
- リールは窓の中を数字の帯が縦に流れる作りで、速さに応じて縦にブレる。真ん中のリールは1コマずつ送る。
- WebGL が使えない端末や、準備が間に合わないとき（始める 0.7 秒、止める 1.5 秒）は CSS 版に戻る。
- 声は VOICEVOX:青山龍星（熱血）：「研究スタート」「リーチ」「チャンス」「押せ」「ステップアップ」「きたー」「全回転」「確定」「ラウンドスタート」「研究ラッシュ突入」、結果の5種類、節目、週の発表。効果音は自前で合成して書き出したもの。
- ゼブラ柄とキリン柄は [effects/patterns.js](../effects/patterns.js) で描く（本物の機種で「出たらほぼ当たり」とされる柄の考え方だけを借りる）。

## 光の部品

| 部品 | 中身 | 出る場面 |
|---|---|---|
| 電飾 | 画面のふちを2色の玉が交互に走る。リーチ中と結果では倍速 | 始める・止める |
| 色フラッシュ | 画面全体がその時の色で光る | 始める |
| ストロボ | 白と色を 0.075 秒ごとに交互に連打する（結果では青1回〜虹14回） | 再変動、リーチ、昇格、すべり、結果 |
| 暗転 | 一瞬すべてを消して無音にする | 結果の直前 |
| 脈打つ光 | 中央から色の光が1秒に2回ふくらむ | 真ん中のリールがゆっくりになってから |
| 光の筋 | 帯と結果の文字の上を白い光が走り続ける | 帯・結果 |
| リールの光 | 止まったリールだけが白く光る | リール停止 |
| 光線 | 結果の後ろで太い光線が回る（虹は7色） | 結果 |
| きらめき | 画面のあちこちで十字の光がまたたく | 始める・結果 |
| 二段爆発 | 中央ではじけた後、左右でもう一度はじける | 赤以上の結果 |
| ゼブラ柄・キリン柄 | 帯や板が白黒の縞（ゼブラ）、黄色と茶の斑（キリン）になる | ゼブラ：リーチの帯（金はときどき、虹は必ず、赤はまれ）。キリン：STEP∞、全回転、保留の玉（虹） |
| 役物 | 巨大なメダルが2本の棒ごと上から落ち、画面にひびが入る | 赤以上のリーチ前 |
| 出玉 | 研究時間1分を100発にしてカウントアップ。玉が噴き出す | 結果のあと |

## 信頼度の色

結果は実際の研究時間で決まる。ランダムなのは「途中で何段階昇格して見せるか」だけ。

| 色 | 今回の研究時間 | 結果の文字 |
|---|---|---|
| 青 | 30分未満 | おつかれさま！ |
| 緑 | 30分〜1時間 | ナイス研究！ |
| 赤 | 1〜2時間 | 激アツ！ |
| 金 | 2〜4時間 | 大当たり！ |
| 虹 | 4時間以上 | 超大当たり！！ |

## 節目と週の発表のきまり

- 節目は、アプリを開いているときに出す。閉じている間に過ぎた節目は、次に開いたときに一番新しいものだけを出す。
- 始めた時刻をさかのぼって入れたときや、ほかの端末で始めた記録は、もう過ぎた節目を出さない。
- 週の発表は、その週に初めて開いたときに一度だけ。先週の記録がなければ出さない。演出がオフなら出さない。

## 止めるときの流れ

色が上ほど長く溜める。虹は「押せ！」を押さなければ約40秒、赤は約33秒、青は約10秒。

| 段階 | 起きること | 長さ |
|---|---|---|
| 1. 暗転 | 暗くして溜める。赤以上は心音 | 0.6秒（赤以上 1.4秒） |
| 1'. ステップアップ | 「STEP1」の板から1枚ずつ叩きつけられ、色が上がる。青は1〜2、緑は2〜3、赤は3、金は4〜5、虹は5のあと「STEP∞」（キリン柄） | 1枚 約0.6秒 |
| 2. 再変動 | リールが回って外れ目で止まり、ストロボと「再変動×2」でもう一度回る。回数は青0・緑0〜1・赤1・金と虹2〜3。3回目からは色が上がることもある | 1回 約2.2秒 |
| 2'. 役物 | 赤は半分、金は8割、虹は必ず。ガタッと2回揺れてからメダルが落ち、ひびと「きたー！」 | 約2.8秒 |
| 3. リーチ | 「リーチ」の帯（ゼブラ柄のことも）、ストロボ、揺れ、「ドン」 | 1.3秒 |
| 4. リール | 左 → 右と止まり、真ん中は1コマずつ送りながら粘る。その間に色が昇格する | 昇格1回 1秒 ＋ 粘り 1.5秒 |
| 4'. 全回転（虹） | 4と5の代わり。キリン柄の「全回転」の帯のあと、3つが同じ数字のまま回って1コマずつ遅くなり、7・7・7で止まって「確定」 | 約7秒 |
| 5. すべり | 赤と金：1コマ手前で止まったと見せ、0.9秒後に最後の1コマへすべって揃う | 0.9秒 |
| 6. 押せ！ | 赤以上（青・緑もときどき）。最後の昇格はボタンを押した瞬間に起きる。押さなければ6秒で進む | 押すまで（最大6秒） |
| 7. 無音の暗転 | 一瞬すべてを消す | 0.3秒（赤以上 0.65秒） |
| 8. 結果 | 結果の文字、ストロボ、光線、電飾、きらめき、粒子、ファンファーレ | 1.3秒 |
| 9. 出玉 | 「獲得 ◯発」が数え上がり、玉が噴き出す。赤以上は上に「ROUND 1」〜（15分で1ラウンド、最大16） | 約2.5〜4秒 |
