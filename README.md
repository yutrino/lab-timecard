# 研究タイムカード

研究室で研究に費やした時間を記録し、「課題研究・セミナー4の学習保証時間」の表に書く週ごとの数字を出す、1画面のWebアプリ。

## 使い方

- **研究を始める／研究を終える** を押すだけ。記録中は画面が緑になる。
- 押し忘れたら、ボタンの下の「始めた時刻を指定する」「終わった時刻を指定する」で後から入れる。
  終了を12時間以上押し忘れていると、開いたときに終わった時刻を聞かれる。
- 曜日の行を押すと、その日の記録の時刻・区分を直したり、足したり、消したりできる。
  区分は最初すべて「研究」。ディスカッションや発表会・練習はここで付け替える。
- 下の「保証表に書く数字」が、表の3列（ディスカッション／研究／発表会・練習）にそのまま写す値。
  `‹` で前の週を見られる。

### 集計のルール

- 週は月曜始まり。その週の木曜日がある月の「◯月◯週」として数える。
- 第5週にあたる週は「4週」と表示されるので、4週の行に足して書く。
- 週の合計を時間単位に四捨五入する。丸める前の値も下に出る。
- 日をまたいだ記録は、0時で分けてそれぞれの日に数える。

## 手元で動かす

```sh
npm start        # http://localhost:8765 を開く
npm test         # 集計と同期マージのテスト
npm run icons    # アイコンを作り直す
```

ビルドは不要。`index.html` `style.css` `app.js` `logic.js` `sw.js` `manifest.webmanifest` `icons/` を
そのまま HTTPS で配信すれば動く（GitHub Pages など）。

## スマホとPCで同期する（任意）

設定しなければ、記録はその端末のブラウザだけに保存される。
同期するには、自分の Google スプレッドシートを保存先にする。

1. Google スプレッドシートを新しく作る。
2. メニューの **拡張機能 → Apps Script** を開き、最初からあるコードを消して [gas/Code.gs](gas/Code.gs) の中身を貼り、保存する。
3. **デプロイ → 新しいデプロイ** で、種類に **ウェブアプリ** を選び、
   「次のユーザーとして実行」を **自分**、「アクセスできるユーザー」を **全員** にしてデプロイする（初回は承認を求められる）。
4. 表示された **ウェブアプリURL**（`https://script.google.com/macros/s/…/exec`）をコピーする。
5. アプリのいちばん下の「同期を設定する」を押し、URLを貼って保存する。
6. ほかの端末では、同じ画面の「ほかの端末で開くリンクをコピー」で作ったリンクを開く。

このURLを知っている人は記録を読み書きできるので、人には教えない。

記録はスプレッドシートの「記録」シートに1行ずつ入る。シートを直接直したり、行を消したり、
ID を空にして行を足したりしても、次の同期でアプリに反映される。

`gas/Code.gs` を後から書き換えたときは、**デプロイを管理 → 編集 → 新バージョン** で更新する（URLは変わらない）。

## ファイル

| ファイル | 役割 |
| --- | --- |
| `index.html` `style.css` | 画面 |
| `app.js` | 打刻・表示・同期 |
| `logic.js` | 週と時間の計算、同期のマージ（テスト対象） |
| `sw.js` `manifest.webmanifest` `icons/` | ホーム画面に追加、オフラインで開く |
| `gas/Code.gs` | 同期先のスプレッドシートに貼るスクリプト |
